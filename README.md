# Genesis Web Application

A modern and responsive web application built with React and JavaScript, featuring a clean UI, mobile-friendly navigation, and smooth user experience.

## ✨ Features
* Responsive navigation bar with mobile hamburger menu and icon toggle.
* Modern layout with custom styling and smooth transitions.
* Built with component-based architecture for optimal performance.

## 🛠️ Technologies Used
* **React** (JavaScript Library)
* **HTML5 & CSS3**
* **Vite** (Build Tool)
